### Build Commands

Use Gradle wrapper tasks from the project root:

* `./gradlew bootRun` - start backend
* `./gradlew test` - run tests
* `./gradlew spotlessApply` - format Java code
* `./gradlew spotlessCheck` - verify formatting
* `./gradlew build` - full backend build
